One joke, one line, no explanation. This entry for the make.fun One-Line Laugh-Off puts a single punchline up against every other entrant's, and a judge model picks the funniest.

## How to run

```sh
python3 main.py
```

Running it creates `/output/entry.txt` holding exactly one line — the joke — and prints that same line to the terminal.

## The joke

> I asked the universe for a sign, and it sent me a CAPTCHA.
